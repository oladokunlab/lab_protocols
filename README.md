# Oladokun Lab — Laboratory Protocol Handbook

Consolidated standard operating procedures for the Poultry Microbiome and Health
Research Group, Kleberg Center CT 335, Texas A&M AgriLife.

> This handbook supplements — but does not replace — institution-approved biosafety,
> chemical-safety, organism-specific, equipment and waste-disposal procedures.

## For new lab members

Start with Chapter 1. All required TAMU training must be completed **before** entry
to the lab, and equipment proficiency must be demonstrated to the PI before use.

## Contributing

Protocol changes go through the PI. Submit corrections as a pull request or raise an
issue describing the change and the reason for it. Include the date and your initials
in the commit message.
